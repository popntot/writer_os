# Writer OS

Voice-first thinking partner for writers. Talk through ideas on walks, refine at a desk; the agent maintains a canonical project narrative across sessions.

**Status**: Pre-MVP. Architecture complete; implementation not yet started.

## Repository orientation

- [`docs/prd.md`](docs/prd.md) — Product Requirements Document (source of truth for product specs)
- [`docs/onboarding.md`](docs/onboarding.md) — How to pick this up on a new machine or in a fresh session
- [`docs/session-log.md`](docs/session-log.md) — Chronological log of work shipped across sessions
- [`docs/agents/`](docs/agents/) — Configuration for AI coding agents (issue tracker, triage labels, domain docs)
- [`docs/adr/`](docs/adr/) — Architecture Decision Records (created lazily as decisions get formalized)
- [`AGENTS.md`](AGENTS.md) — Shared substrate every AI coding agent reads before working in this repo
- `CONTEXT.md` — Domain glossary (created lazily as terms get resolved)

## If you're picking this up

Read [`docs/onboarding.md`](docs/onboarding.md) first. It points to everything else in the right order.
