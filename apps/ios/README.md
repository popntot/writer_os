# Writer OS — iOS app

SwiftUI iOS app. Voice-first session UI ships in slice #8; this slice (#5) ships the project list + create flow as the first end-to-end iOS↔backend tracer.

## Project file generation

The `WriterOS.xcodeproj` is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` and is **not committed**. Regenerate after pulling, or after editing `project.yml`:

```sh
pnpm ios:generate    # from repo root
# or
cd apps/ios && xcodegen generate
```

If you don't have XcodeGen: `brew install xcodegen`.

## First-time signing setup (one-time per developer)

Required before a device install will work. Apple Developer Program enrollment is a hard prerequisite (already done by Will).

1. `pnpm ios:generate` to produce `WriterOS.xcodeproj`.
2. `pnpm ios:open` to open in Xcode.
3. Select the `WriterOS` target → **Signing & Capabilities** tab.
4. Set **Team** to your Apple Developer team. Xcode will prompt for Apple ID login if not already connected.
5. **Automatic** signing is on by default; Xcode provisions the cert + profile when you first run.

Optional: persist your team ID across regenerates by creating `apps/ios/project.local.yml` (gitignored):

```yaml
settings:
  base:
    DEVELOPMENT_TEAM: YOUR_TEAM_ID_HERE
```

Then update `project.yml` to include it (already wired — uncomment the include if you use it).

## Running on the iOS Simulator

```sh
pnpm ios:open                # then ⌘R in Xcode, choosing an iPhone simulator
# or, headless build:
xcodebuild -project apps/ios/WriterOS.xcodeproj -scheme WriterOS \
  -destination 'platform=iOS Simulator,name=iPhone 17,OS=latest' build
```

## Running on a physical iPhone (dev install)

1. Plug your iPhone into your Mac (or pair wirelessly via Xcode → Window → Devices and Simulators).
2. The first time, on the iPhone: **Settings → General → VPN & Device Management → trust** the developer certificate that appears.
3. In Xcode, select your iPhone from the run-destination dropdown (top of the window).
4. Press **⌘R**. Xcode builds, signs, transfers, and launches.

## Connecting to the backend

The app stores its API base URL and bearer secret in `UserDefaults`. On first launch the app shows a setup screen asking for both. Tap **Settings** in the project list toolbar to clear and re-enter.

For local development with `pnpm api:dev` running on your Mac:

- Mac IP: `ipconfig getifaddr en0` (or check System Settings → Wi-Fi → Details)
- API base URL: `http://<Mac IP>:8787` (e.g. `http://192.168.1.10:8787`)
- API secret: matches `WRITER_OS_API_SECRET` in `apps/api/.dev.vars`

The Mac and iPhone must be on the same Wi-Fi network. On a public/coffee-shop network, isolation may block this — use a personal hotspot or local network.

## Tests

```sh
pnpm ios:test
```

Runs the XCTest suite (`WriterOSTests` target) on the iOS Simulator. Currently 3 tests covering JSON encode/decode for the Project model.

## Backend dependency

`apps/api` (the Cloudflare Worker) must be reachable for the project list to load. The Worker requires a valid `DATABASE_URL` — Supabase free-tier or local Postgres. See `apps/api/README.md` for backend setup.

## TestFlight build

The TestFlight archive path is driven by `apps/ios/project.yml`; `WriterOS.xcodeproj` is
generated and remains uncommitted. The finalized bundle identifiers are:

- App: `com.popntot.WriterOS`
- Tests: `com.popntot.WriterOS.Tests`

Prerequisites:

- Apple Developer enrollment and App Store Connect setup are available for Gate #23.
- Xcode and Xcode command line tools are installed.
- XcodeGen is installed (`brew install xcodegen`).
- Automatic signing has been configured in Xcode at least once for the `WriterOS` target.
- `DEVELOPMENT_TEAM` is set to the Apple Developer Team ID in the shell that runs the build.

```sh
export DEVELOPMENT_TEAM=ABCDE12345
pnpm ios:build
```

The command regenerates the Xcode project, archives the Release build, exports with automatic
App Store Connect signing, and writes the IPA to:

```sh
apps/ios/build/WriterOS.ipa
```

`MARKETING_VERSION` in `project.yml` is the user-visible semantic version and starts at `0.1.0`.
Bump it for user-visible release changes. `CURRENT_PROJECT_VERSION` is the build number and must
increase for every submitted archive; `pnpm ios:build` increments it before archiving and rolls the
change back if archive/export fails.

The app icon is a functional placeholder generated by
`apps/ios/scripts/make-placeholder-icon.sh` into `Assets.xcassets/AppIcon.appiconset`. Replace it
with designed production artwork before a public TestFlight. The launch screen intentionally uses
Xcode's generated blank launch screen via `INFOPLIST_KEY_UILaunchScreen_Generation: YES`; no
storyboard is committed for this default.
