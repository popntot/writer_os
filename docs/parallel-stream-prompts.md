## How to read worker progress

Status is recorded **per-worktree**. From each worktree:

```bash
cd ../writer_os-stream-a   # or -stream-b
node "${CLAUDE_PLUGIN_ROOT:-$HOME/.claude/plugins/cache/openai-codex/codex/1.0.4}/scripts/codex-companion.mjs" status --all
```

Or via slash command in this session: `/codex:status task-<id>`. Handoffs land in `docs/handoffs/stream-<letter>-<slug>.md` when each worker exits.
